## 게시 조건

테스트 APK는 작업 브랜치에서만 제공한다. 업데이트 저장소의 JSON과 Releases는 변경하지 않는다.
휴대폰 검증 및 독립 교차 테스트 → main 병합·태그 → 사용자의 **배포 시작해** 승인 후
`scripts/publish-android-update.ps1`로 게시한다. 업데이트 확인은 설정 → 업데이트에서만 실행된다.
